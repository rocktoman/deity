## 4. V0.5 验收证据

- Plan 工具集合由运行时策略过滤；写、删、Shell 与未知效果工具不会因提示词或仓库内容获得授权。
- Build 使用独立 Run，校验计划 hash、TTL、需求来源、工作区快照和逐路径 dirty allowlist；开始执行前再次校验快照。
- Python、Java、TypeScript/TSX 定位返回 1-based 位置、来源与置信度；缓存包含内容 hash 失效。
- 补丁覆盖 preimage、精确唯一上下文、UTF-8/BOM、CRLF、原子替换、binary、symlink、`.git` 与 submodule 拒绝路径。
- ChangeSet、FileChange、WorkspaceSnapshot、CodeIndex、Verification 与 Git diff Evidence 进入 SQLite 审计事实；FileChange 在 ToolCompleted 持久化后记录。
- Verification 命令先持久化后执行，支持权限、固定 argv、超时、输出上限、重复检测和进程组取消；聚合只接受完整的已提交检查。
- v3→v4 在迁移前生成并验证 `.v3.bak`，损坏备份会阻断迁移。
- V0.5 全部开关默认关闭，A12 验证旧路径兼容。
