## 事实与边界

- SQLite v1→v2 迁移前复制并验证备份；历史查询保留。Checkpoint 采用规范 JSON SHA-256；损坏快照回退到前一有效快照。旧 v1 Run 不具备足够事实时不能续跑。
- 完整模型轮次先于工具 intent；tool outcome、模型可见消息和完成事件同事务提交。崩溃后的未知结果只供人工核查，不自动派发旧工具。恢复创建同一 Task 的后继 Run。
- 本地工作区指纹覆盖受限文件内容与 Git HEAD，超过 10,000 个文件或 100 MB 时会拒绝恢复预检。工作区路径校验不是 OS 沙箱。
- SDK 隐式重试已关闭；Core 最多三次模型尝试，语义流片段后不重试。`Retry-After` 当前识别数值秒数；非数值头回退到指数退避。
- Linux/macOS 受控 Shell 使用进程组 TERM/KILL。Windows 进程树清理未纳入 V0.3 支持声明。R04 验证受控 Shell 收敛不超过 5 秒；未形成独立的模型/审批 P50、P95、最大值分布报告。
- L3 通过功能断言不等于所有故障注入均由真实厂商运行；R01–R06 使用确定性模型、临时数据库及隔离进程。

远程 CI 的 Ubuntu/macOS × Python 3.12/3.13 结果需以对应 GitHub Actions 运行记录为准。
