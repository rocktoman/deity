# ADR-009：明确指定目标的单文件删除

状态：已采纳。

## 决策

提供 `delete_file(path)` 工具。它沿用工具参数校验、工作区边界、授权、执行结果与审计管线。当前用户请求须同时包含删除意图和目标相对路径；否定请求不授权。仅删除工作区内的普通单文件，拒绝目录、symlink、`.git` 路径和越界路径。`workspace_write = "auto"` 时，符合以上条件的调用无需再次询问；`ask` 仍逐次确认，`deny` 始终拒绝。Shell 自动策略继续拒绝 `rm`。

## 理由与限制

用户明确要求删除文件时，让模型自改策略或放开 Shell 命令都扩大了权限。专用工具将可执行动作限制为单个文件，并保留每次调用的 intent、outcome 和事件。基于用户文本的目标匹配是保守规则：省略文件名的指代可能被拒绝，用户需再次写出路径。路径检查不能替代操作系统沙箱，也不能消除检查与删除之间的竞争窗口。

## 验证

单测覆盖明确请求、无授权、否定请求、越界、目录、symlink 和 `.git`；集成测试覆盖自动模式的完整模型调用与文件删除。
