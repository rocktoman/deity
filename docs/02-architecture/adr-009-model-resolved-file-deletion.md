# ADR-009：模型解析目标的单文件删除

状态：已采纳。

## 决策

提供 `delete_file(path)` 工具。模型根据当前请求和同一会话的历史选择目标路径，工具不解析用户文本中的关键词或文件名。工具沿用参数校验、工作区边界、授权、执行结果与审计管线；仅删除工作区内的普通单文件，拒绝目录、symlink、`.git` 路径和越界路径。`workspace_write = "auto"` 时无需再次询问；`ask` 仍逐次确认，`deny` 始终拒绝。Shell 自动策略继续拒绝 `rm`。

## 理由与限制

用户明确要求删除文件时，让模型自改策略或放开 Shell 命令都扩大了权限。专用工具将可执行动作限制为单个文件，并保留每次调用的 intent、outcome 和事件。省略文件名的指代由模型根据会话历史解析；目标不唯一时应先澄清。`auto` 模式信任模型在语义上选择目标，工具层无法证明用户真正意图，因此不应把它描述为完整的删除授权校验。路径检查不能替代操作系统沙箱，也不能消除检查与删除之间的竞争窗口。

## 验证

单测覆盖无授权、越界、目录、symlink 和 `.git`；集成测试覆盖同一会话先创建文件，再用“删除刚才新建的文件”删除。
