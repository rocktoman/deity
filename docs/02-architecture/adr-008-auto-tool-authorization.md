# ADR-008：显式自动工具授权

状态：已采纳。

## 决策

CLI 配置中的 `shell` 和 `workspace_write` 增加 `auto` 选项。默认仍为 `ask`；用户显式选择 `auto` 后，工作区内的 `write_file`、`apply_patch` 不再逐次询问，Shell 只自动运行受限的测试与检查命令。其他 Shell 命令直接拒绝，不弹确认框。`deny` 始终优先；工具参数校验、工作区路径边界、审计、超时和取消仍由原管线执行。运行与恢复使用同一授权规则。

## 理由与限制

连续编码任务经常需要多次文件写入与测试，逐次审批会阻断正常交互。自动 Shell 使用命令白名单以拒绝明显的破坏性或远程命令，例如 `rm`、`git push` 和 `sh -c`。允许的测试命令及工作区脚本本身仍可能有副作用；该白名单不是 OS 沙箱，也不应被描述为完整的命令安全分析。需要更强隔离时应使用独立工作区和操作系统级限制。

## 验证

配置测试验证 `auto` 仅在显式设置时启用；集成测试验证文件写入和允许的 Shell 命令无需审批、破坏性 Shell 命令被拒绝；单元测试覆盖命令白名单与越界路径。
